# Blue Whale V0.12 Changelog

## Type

Frontend / Website / Information Architecture

## Main changes

- Repositioned homepage from procurement landing page to corporate website.
- Kept sourcing as a dedicated secondary business page.
- Added reusable corporate header and footer.
- Added `/about`.
- Added `/business`.
- Added `/business/sourcing`.
- Added `/technology`.
- Added `/contact`.
- Reworked global visual system in `app/globals.css`.
- Replaced default Create Next App metadata.
- Restyled `/inquiry` while preserving its existing submission logic.
- Preserved `/workspace`.
- Added permanent `VERSIONING.md` odd/even release convention.

## Design direction

- Minimal technology aesthetic.
- White / slate base with cyan and blue energy accents.
- Large editorial typography.
- Grid, glow and system-panel motifs.
- More visual rhythm than the previous single landing page.
- Designed so future business modules can be added without rebuilding the homepage.
