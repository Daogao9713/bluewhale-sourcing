# X0.46 安装与交付

基线：X0.45。分支：`frontend/x0.46-smart-factory`。

此版本新增 Three.js 及其开发期类型包，随附 npm lockfile。没有数据库迁移，没有新增环境变量，不需要 MES 或 AI 密钥。保持现有 Next.js / Vercel 部署方式。

```bash
npm ci
node scripts/test-factory.mjs
npm run build
```

审查并合并更新后按现有流程部署，访问 `/smart-factory`。官网导航和 `/solutions` 均有入口。路由在服务端输出页面框架，Three.js 仅在该页面浏览器端按需加载。

## 客户演示检查

- 在目标桌面浏览器检查 WebGL、旋转、缩放、工序点击和动画。
- 使用手机检查堆叠布局与参数、聊天输入；使用键盘检查输入、按钮和记录页签。
- 启用系统“减少动态效果”时模型保持静态，数据和交互继续；浏览器标签页隐藏时暂停推进。
- 点击“暂停仿真”应冻结时间、计件和采样；“重置演示”清空本次状态。
- 完整演示顺序及数据边界见 `CHANGELOG-X0.46.md`。

## 回退

按项目既有发布流程回退本 PR / 提交并重新构建即可；本版本没有服务端数据写入，也无需数据库回滚。
