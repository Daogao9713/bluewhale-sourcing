# X0.46 · Smart Factory Experience

基于 X0.45 `ecbf2c6`。沿用星玥阳 X0.x 命名与偶数版本以前端体验为主的约定。

- 新增 `/smart-factory`：Industrial Liquid Glass 全屏工业控制台，中文界面。
- 官网桌面与移动导航、行业方案页新增入口；加入 sitemap 与独立 metadata。
- Three.js 按需加载的 3D 产线：原材 → 整平 → 无纺布擦洁 → 覆膜 → 打码 → 冲压 → AOI + 3D 测量。支持旋转、缩放、视角切换、工序选择、冲床/辊轮/机械手/工件/扫描动画。
- 7 个参数控制，速度、送料、覆膜、擦洁、打码与上下料能力联动；有效产能受瓶颈限制，缓冲满载暂停。
- 平面度单侧 Cpu（界面简称 Cpk）、BURR、YIELD、缓冲库存、产出与功率；32 件滚动窗口、逐步响应及趋势。
- 稳定、超速、覆膜失配、下料积料、模具磨损场景。
- 本地规则式 AI 演示：问答、MES 批次依据、实时诊断、手动执行、自动接管、调参前后对比、操作日志。执行前重新诊断当前参数，防止旧方案覆盖新状态。
- 磨损不可由降速消除；停线、模拟检查、手动复产。未完成检查时切换场景也不能清除故障。
- 120 批合成 MES 数据、工况筛选与分页，所有统计均从同一批数据计算。
- 针对移动端布局、键盘操作、减少动态效果、页面隐藏暂停、WebGL 失败提示及资源释放进行了实现。

## 数据来源与边界

参考用户提供的 CPK 报告结构（23 个特征、32 组样本），仅采用匿名演示参考：平面度 USL 0.600 mm、均值约 0.1906 mm、标准差约 0.0721 mm、单侧能力约 1.89。原始工作簿、客户与供应商标识、原料号及逐件测量值不进入仓库或页面。

其余参数、缺陷率、功率、MES 记录与响应关系为合成场景。良率独立建模，不能由单个尺寸的 Cpk 直接换算。动态滚动窗口不是完成稳定性验证的量产能力结论。MES 记录与 AI 规则来自同一演示模型，不宣称统计因果验证。速度窗口和质量目标仅用于演示。

全部控制仅改变浏览器内仿真状态；没有真实 MES、PLC、机器人、LLM 或数据库调用。现有官网咨询 AI、企业 Agent、认证、CMS 与生产数据库保持原有架构。独立全屏体验页内使用专用 AI 窗口，避免与 FloatingAI 重复。

## 推荐演示顺序

1. 从官网“智慧工厂”进入，旋转模型并点击工序。
2. 选择“超速冲压”，观察 10–20 秒；左侧毛刺升高、良率和能力下降。
3. 问“为什么良率下降？”，查看 MES 匹配依据后“执行协同优化”。
4. 观察工艺参数同步变更、动画减速和后续 32 件窗口恢复；查看前后对比与操作记录。
5. 开启 AI 自动接管，选择“下料积料”，展示自动协调机械手与冲压速度。
6. 选择“模具磨损”，展示自动停线、人工检查与手动复产。
7. 打开“MES 批次数据”，切换相近工况、翻页查看历史；查看页面底部统计口径。
