# X0.47 · 浏览器性能优化

基于 `5ec63b5`（main / X0.46），本次以性能和后台入口收纳为主。公开站其他页面保持现有视觉，智慧工厂保留原有功能布局。

## 改动

- 从桌面导航、手机菜单和全站页脚移除 WORKSPACE 入口。新路径：**关于我们 → 页面底部「内部访问」→「员工登录」**。折叠默认关闭，不预加载后台；原 `/workspace` URL 和登录验证保留。后台页面及子页面增加 `noindex, nofollow`。隐藏入口不替代身份验证。
- 公开站 AI 面板在首次点击后才下载、挂载，关闭后保留会话组件，重新打开可继续使用。
- 禁止导航中的智慧工厂链接自动预加载，普通访客不再因导航可见而提前下载工厂页面脚本。
- 3D 动画上限 30 FPS；场景离屏、标签页隐藏或 WebGL 上下文丢失时停止帧循环；仿真暂停后按交互需要重绘，减少动态效果模式下只随数据或视角更新。
- 桌面像素比上限从 1.75 降到 1.5；触屏设备上限 1.25，并关闭实时阴影。复用立方体几何数据，简化透明材质；卸载时清理帧回调、监听器、观察器和 GPU 资源。
- MES 批次表仅在参数、磨损或表格自身交互改变时更新，避免随监控计时重复渲染。
- 智慧工厂采用白底、蓝色强调和深色正文，移除该页毛玻璃、光晕和渐变，保留质量告警语义色。
- 首页产品与案例图片补充响应式 `sizes`；修复页脚引用不存在的图标文件。

## 验证与测量

2026-09-11，使用 X0.46 和修改后生产构建、Chromium 152、1440×1000 视口、DPR 2 分别测量。浏览器使用软件 WebGL；数据库与邮件仅使用本地占位配置，不连接生产服务。

| 指标 | X0.46 | X0.47 |
| --- | ---: | ---: |
| `/about` 加载后 1.8 秒内自动请求的 JS 解压体积（含自动预加载） | 620,872 B / 12 文件 | 518,188 B / 9 文件 |
| 暂停仿真后 3 秒内屏幕重绘 | 18 | 0 |
| 模型离屏后 3 秒内屏幕重绘 | 169 | 0 |
| 相同 CSS 尺寸下画布像素尺寸 | 1379×735 | 1182×630 |

该公开页 JS 请求体积减少约 **16.5%**；高 DPI 桌面画布像素数量减少约 **26.5%**。JS 指标包括框架及预加载，不是单一组件大小，也不等同于压缩网络传输体积或全站提速比例。软件渲染环境下不将帧数换算成真实设备 CPU/GPU 占用或 Lighthouse 分数。

已通过：

- `npm run build`（包含 TypeScript 检查）；`npm run lint`；现有 `node --test scripts/test-factory.mjs` 共 10 项。
- 浏览器：入口默认折叠、跳转到后台登录页面、后台 noindex、AI 首次打开/关闭/重开、暂停零重绘、暂停时相机仍可操作、离屏零重绘、回到视野继续动画、减少动态效果模式、WebGL 丢失后的降级提示。
- 90 秒引导演示的全部阶段（通过「下一步」推进）、390px 手机页面无横向溢出、手机菜单无后台入口、页面无未捕获 JavaScript 错误。

浏览器回归脚本：`scripts/test-browser-performance.mjs`。可在本地已安装 Playwright/Chromium 且完成生产构建后执行 `node scripts/test-browser-performance.mjs`；脚本会启动仅监听 `127.0.0.1:3101` 的临时服务（可用 `TEST_PORT` 修改），完成后关闭。

尚未验证生产数据库、真实 AI 回复、询盘邮件投递与真实手机 GPU；这些服务没有在本次改动中调整。

## 安装

无新增运行时依赖，无数据库迁移；沿用原环境变量。合并后运行 `npm ci`、`npm run build`，再按现有部署方式更新。PR 不自动合并或部署。
