# Workspace News Link

V0.17 CMS is available at:

`/workspace/news`

It remains a separate workspace route to avoid overwriting the existing large Sourcing OS shell.

Recommended sidebar label:

`Company News`

Recommended link:

```tsx
<Link href="/workspace/news">Company News</Link>
```

The CMS uses the same `BLUEWHALE_ADMIN_KEY` as the workspace APIs.
